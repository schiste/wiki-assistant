# WAIT — Wiki Aware Intelligent Tool

An agent that helps Wikipedia editors navigate policy/rules and templates, assists with small
JS/CSS/Lua (Scribunto) coding, and helps editors discover existing tools before building new
ones.

- **Architecture, security, and product plan:** [`docs/architecture-plan.md`](docs/architecture-plan.md)
- **Rollout plan to V1 (phases, epics, checklist):** [`docs/rollout-plan.md`](docs/rollout-plan.md)

## Status

Phase 0 (foundation) — repo structure, issue/project tracking, and Toolforge tool setup in
progress. See the rollout plan for the full phase breakdown.
